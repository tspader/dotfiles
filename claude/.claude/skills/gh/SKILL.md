---
description: Using the GitHub CLI for search
---

Use this when searching for whether something exists on GitHub:
- Never, ever clone repositories. I will clone. Cloning arbitrary code is dangerous
- Generally, I'm not interested in results with less than a hundred or so stars unless I ask otherwise
- Return a Markdown table with columns for:
    - Repo (e.g. `tspader/sp`)
    - Stars
    - Last committed date
    - Brief description (one sentence max) if needed
